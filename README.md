# CLI Word Counter

A simple **command-line word counter** built with **TypeScript and Node.js**.

This project was developed during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** as part of my early experimentation with building, packaging, and publishing **TypeScript-based CLI applications as npm packages**.

## About

CLI Word Counter is a terminal-based application that allows users to enter text and calculate its word count through an interactive command-line interface.

The project was created as a practical exercise for learning TypeScript, handling user input, implementing text-processing logic, and building an interactive CLI application.

## Features

* Interactive command-line interface
* Word counting
* Text input through interactive prompts
* Styled terminal output
* Loading animations
* Simple text-processing logic
* Runs directly through `npx`

## Usage

The published package can be run directly using:

```bash
npx adil-word-counter
```
